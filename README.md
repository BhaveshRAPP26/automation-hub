# automation-hub
Automation Hub

Please select a program that you want to execute, from the sidebar.
### CheckEm
Validates link tracking parameters
### GA4 Request Parameter Breakdown
Breaks down GA4 Request Parameters and allows extraction of specific parameters
### GTM Snippet Identifier
Identifies the GTM Snippet on a given page
### HTML ID Extractor
Extracts all HTML IDs from a given page
### OneTrust Modal Identifier
Identifies the OneTrust Modal on a given page
### OneTrust QA
Conducts scenario-1 OneTrust QA (accept cookies)
